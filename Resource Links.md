# 🔗 Resource Access

## 📈 Labour Planning Tools

### 1️⃣ 📂 Roster Validation
**Location:**  
`\\ant\dept\LMA\EU Capacity Planning\ALPS\Roster Changes\UK\[Site Name]`

Shared network folder where you validate and track roster (staffing schedule) changes for each UK site before they feed into ALPS.

---

### 2️⃣ 📊 ALPS
🔗 https://amzl-dub.alps-basecamp.lamps.amazon.dev/select_site

Amazon Logistics Planning System (ALPS) – the core tool used to generate weekly labour plans, including headcount, shift allocation, VET, and VTO.

---

### 3️⃣ 📋 SSPOT
🔗 https://sspot.dub.corp.amazon.com/

Self-service planning and operations tool used to retrieve site data and reports that support labour planning decisions.

---

### 4️⃣ 🌍 Horizon
🔗 https://horizon.harmony.a2z.com/horizon/amzl

The AMZL planning portal used to generate input files, launch plans, and manage the end-to-end planning workflow.

---

### 5️⃣ 🤖 AgentSpaces
🔗 https://agentspaces.amazon.dev/app

Amazon's AI assistant for automating planning tasks, querying ALPS, and providing AI-powered support through chat.
